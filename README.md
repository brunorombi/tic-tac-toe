🎮 Tic Tac Toe

Jogo da velha desenvolvido em JavaScript puro usando Factory Functions, Closures e Module Pattern para organizar o código e encapsular o estado do jogo.

✨ Funcionalidades

Dois jogadores com nomes personalizados

Alternância automática de turnos

Detecção de vitória e empate

Sistema de pontuação

Reset do jogo e do placar

Interface dinâmica manipulando o DOM

🧠 Arquitetura

Gameboard → gerencia o tabuleiro

GameController → regras do jogo e estado

ScreenController → interface e renderização

Separação clara entre lógica e UI.

🧩 Tecnologias

HTML • CSS • JavaScript (ES6)
